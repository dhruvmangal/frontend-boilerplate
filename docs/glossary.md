# Words you'll see

| Word                            | Meaning                                                                                      |
| ------------------------------- | -------------------------------------------------------------------------------------------- |
| **API**                         | The way your app talks to a server to load and save data.                                    |
| **Backend / server**            | The computer program that stores your data. This project is the _frontend_: what people see. |
| **Fake data / mock**            | Pretend data built into the app, so you can build screens before a backend exists.           |
| **Component**                   | A reusable piece of screen, like a button or a card.                                         |
| **Page / screen**               | A whole view with its own address, like `/recipes`.                                          |
| **Route**                       | The address of a page (`/recipes/3`).                                                        |
| **Hook**                        | A reusable piece of logic whose name starts with `use` (`useRecipes()`).                     |
| **Generator**                   | `npm run generate`: creates files for you in the right shape and place.                      |
| **Expo / Expo Go**              | A toolkit for phone apps, and a free app to try yours on your own phone.                     |
| **Emulator / Simulator**        | A pretend phone running on your computer (Android Emulator, iPhone Simulator).               |
| **Capacitor**                   | Wraps your website into a real phone app.                                                    |
| **Electron**                    | Wraps your website into a real desktop app.                                                  |
| **Docker**                      | Runs an app inside a sealed box with everything it needs.                                    |
| **Build**                       | Turning your code into the finished thing people install or visit.                           |
| **Terminal**                    | The window where you type commands like `npm run dev`.                                       |
| **localhost**                   | "This computer". http://localhost:5173 is your app running on your own machine.              |
| **Theme**                       | The colors, corners and fonts. Set in `project.config.json`.                                 |
| **Typecheck**                   | An automatic check that catches many mistakes before you run the app.                        |
| **Test**                        | A small program that checks a feature still works. `npm test` runs them all.                 |
| **Environment variable (.env)** | A setting given to the app from outside the code, like the backend address.                  |
